HOW-TO:
----

Install AUTOSCRIPT ACTIONS file to Actions.
Need to install AutoHotKey
Need to add MT_PostResize to the FIFTH spot in the Scripts preset scripts section.

Cutlines:
---
1. Drag in a file for formatting.
2. Run MT_AutoScript_MASTER.
2a. Run MT_SlapScript for slaps / polaroids / boxes / rectangles.

Tiling:
---
MT_FullPrep_Dynamic: Makes specific rows / tile amount, with reg mark option.
MT_FullPrep_FullSheet: No prompts just tiles and reg marks a full sheet
MT_TileOnly_Fullsheet: Same as fullprep just without the reg marks, can iterate through all files
MT_RegMarks: Just does the regmark part
